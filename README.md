## 📌 Project Overview

Retail Sales Hub is a modern full-stack retail analytics and sales management platform built using the MERN stack. The application provides advanced sales analytics, customer insights, performance reports, real-time filtering, and interactive dashboards for retail businesses.

The platform is designed with a professional enterprise-grade UI and optimized backend APIs capable of handling large retail datasets with filtering, pagination, aggregation, and analytics features.

## Frontend

- Framer Motion
- Recharts
- React Router DOM
- Context API
- Lucide React Icons

## Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## Deployment
- Frontend: Render
- Backend: Render
- Database: MongoDB Atlas

## 🚀 Installation Guide
### Clone Repository
```
git clone https://github.com/gulshankumar143/Retail-Sales-Hub
```
### Backend Setup
```bash
cd backend
npm install
npm run dev
```
Backend Runs On:
```
http://localhost:7000
```
### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Frontend Runs On:
```
http://localhost:3000
```
